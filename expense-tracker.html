Setting Up Notion Integration
Step 01
Create a Notion Integration
Go to notion.so → Click your workspace name (top left) → Settings → Integrations → Create new integration. Give it a name like "Spendly". Copy the Internal Integration Token.
Step 02
Create a Database in Notion
Create a new page in Notion. Type /database and choose "Table – Full page". Name it "Expenses". Add these columns:
Name → Title (default)
Amount → Number
Category → Select
Date → Date
Notes → Text
Step 03
Connect Integration to Database
Open the database page → Click ••• (top right) → Add connections → Search for your integration name → Click to connect.
Step 04
Find Your Database ID
Open the database in your browser. The URL looks like:
notion.so/workspace/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx?v=...
Copy the 32-character ID between the last / and the ?
Step 05 — Apple Pay Automation
Set Up iOS Shortcuts
Open the Shortcuts app → Automation tab → + New Automation → Apple Pay → When payment is completed. Then add a "Open App" action to open Spendly (saved to Home Screen). This will prompt you to log the transaction immediately after paying.
Step 06 — Add to Home Screen
Install as iPhone App
In Safari, open this page → Tap Share button → "Add to Home Screen". Spendly will appear as a full-screen app icon.
